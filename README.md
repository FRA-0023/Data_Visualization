# Data Visualization Project
---
This project explores how the structure of European trade has evolved between 2013 and 2024, going beyond simple growth figures to uncover deeper structural changes.

Using official EU trade data, the analysis compares imports and exports across countries and sectors, focusing on three key dimensions: scale (absolute growth), structure (sectoral composition), and momentum (relative growth). Particular attention is given to the rising role of services, ICT, and financial activities, and to how trade growth is distributed geographically across EU Member States.

The project combines data cleaning, aggregation, and exploratory analysis with visual storytelling techniques (maps, bar charts, slope charts, and comparative views) to make complex economic dynamics accessible and interpretable.
The goal is not only to measure how much European trade has grown, but to explain how and where its underlying structure is changing.
